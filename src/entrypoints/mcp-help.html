Connect your AI app to Darb

The optional MCP companion connects a desktop AI app to the courses you choose to share. Ordinary study features work without it.

1. Install the companion

With Node.js 20.19+ installed, run these commands in your terminal:

npm install --global @khalidrouissi/darb-mcp
darb-mcp --version

Guided setup is introduced in companion 0.5.5. Check the version available on npm; the extension and companion have separate versions. Guided/live installation currently supports Linux desktop with Brave, Chrome or Firefox.

2. Choose what to share

In Assistant, select courses/playlists. For live access, click Save live access settings, approve native messaging (and optional data consent on Firefox), then Download private connection file. Keep its contents private.

For read-only access, choose Export selected data instead. A snapshot does not update itself or open videos.

3. Run setup

With companion 0.5.5 or a release supporting the wizard:

darb-mcp setup

Choose your AI app, live/snapshot mode, browser for live mode, and downloaded file. Supported Codex desktop installations can be detected without a separate terminal CLI.

Explicit setup for older companions

This route expects the client's terminal executable in PATH. Replace the path and browser:

darb-mcp setup --client codex --browser brave --connection /absolute/path/darb-connection.json

Use claude for Claude Code. If Zsh suggests changing codex to .codex, answer n.

For a snapshot:

darb-mcp setup --client codex --snapshot /absolute/path/darb-snapshot.json

See the package guide for manual stdio configuration when the client command is unavailable.

4. Reconnect and test

  1. For live mode, return to Assistant and save live access settings again.
  2. Keep the selected browser profile open.
  3. Restart/reconnect the AI client and start a fresh session.
  4. Ask it to make a real tool call:
Use Darb to list my shared courses and show my next session.

Success means a shared course is returned. An install or registration message alone does not verify browser access.

Permissions and privacy

Selection drafting and playback requests are separate opt-ins. Review proposed playlist saves and playback inside Darb. The assistant cannot mark sessions completed; notes, folders, tags and graph layout are excluded.

The bridge communicates locally, but your AI provider may process the data returned to its client. Disconnect and revoke rotates access. Reconnection requires a fresh private file; revocation does not erase data already returned.

If it doesn't connect

  • Missing tools: confirm registration in your client's MCP settings and open a fresh session.
  • Disconnected browser: open the paired profile and save live access settings again.
  • No courses: save the sharing selections, or export a new snapshot.
  • Node/package moved: rerun setup to refresh the browser host.
